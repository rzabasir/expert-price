# Expert Price & Stock Manager

WooCommerce plugin by **Hilawin Software Development Group** (Mohammadreza Basir).

Edit SKU, regular/sale price, stock quantity, stock status and "sold individually" for all products and variations in one table, with:

- Inline editing, variation rows, search by name or URL, category/brand/stock filters, items-per-page selector, resizable columns
- XLSX export with selectable columns and templates
- Changes dashboard (who changed prices/stock, today / yesterday / 7 / 30 days), one-click revert, logs auto-purged after 32 days
- Product delete flow with Rank Math redirect option
- Persian (fa_IR) translation, Jalali dates, lazy-loaded code

See [`readme.txt`](readme.txt) for the changelog. Requires WordPress 6+, WooCommerce, PHP 7.4+.

## Install

Zip the folder as `expert-price-manager/` and upload it via Plugins → Add New → Upload, or clone into `wp-content/plugins/`.
